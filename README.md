# The Zinat Chronicles — A Kingdom Written in Starlight

A mobile-first, self-contained interactive dark-fantasy surprise for Zinat, from Huzaif.

## Run it locally

1. Download and unzip the project.
2. Open `index.html` in Chrome, Edge, Safari or Firefox.
3. On a phone, open the hosted GitHub Pages URL after publishing (steps below).

No build step, package installation, API key, account, backend or database is required. The visual assets are included in `assets/`.

## Publish free with GitHub Pages

1. Sign in to GitHub and create a **new public repository** (for example `zinat-chronicles`).
2. Upload `index.html`, `README.md`, and the `assets` folder into the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the deployment to complete. Your shareable address will be shown on the Pages settings screen, usually `https://YOUR-USERNAME.github.io/zinat-chronicles/`.

## Notes

- Sound effects are synthesized in the browser and remain off until the visitor enables them. No music is autoplayed.
- All story progress is local to the open page; no personal information is collected or sent anywhere.
- The project uses Google Fonts when online; it falls back to installed serif and sans-serif fonts when offline.
- To change the message, edit the letter text in `index.html`.
